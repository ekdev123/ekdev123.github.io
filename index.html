Welcome!
I'm Eldar and I'm pleased you're here.

I'm a Technical Support Engineer at AVEVA, where I work across PI Data Archive, Asset Framework, and PI Web API to troubleshoot the systems enterprises rely on to capture, contextualize, and move industrial time-series data, handling everything from PI Connector and Adapter communication issues to architecture and performance bottlenecks. My coding journey started in college with a simple Java grade calculator that left me fascinated by how things work behind the scenes, and that curiosity hasn't really let up since. These days I build side projects, from small web apps to API integrations, to keep sharpening those skills outside of work. This site is where I share what I've been working on.
